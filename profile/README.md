# Where new frontiers become real

**The full general-purpose AI stack for systems engineers, without the datacentre.**

Data retrieval, browser and computer use, specialised models and licensed multilingual data at origin, with results verifiable at source. Built for industry and regulation, from Linux and quantum to satellites, drones, robots and process plants.

## Why systems engineers choose Pauhu

- **Runs on your hardware.** Models and tools run on the target system, offline when the mission needs it.
- **Clean interfaces.** Command-line tools and documented APIs that slot into your existing toolchain, CI and test benches.
- **Traceable inputs.** Licensed multilingual data comes straight from its publisher, with its version date and retrieval time, ready for requirements and audit trails.
- **Verifiable results.** Answers and runs carry a receipt that anyone can check offline, so verification and validation evidence travels with the result.
- **Open source.** Apache-2.0 tools you can read, build and extend.

## What you can build

| System | Start here |
| --- | --- |
| Linux systems | `pauhu-origin`: cited answers about your own code and history |
| Quantum systems | `pauhu-quantum`: repeatable, verifiable simulator runs with signed settings |
| Industrial systems | Receipts for vision inspection, factory data hubs, robots, drones and more, arriving one at a time |

Releases and packages for these tools are listed on their repository pages.

## Get started

1. **Sign in with GitHub** at [pauhu.dev](https://pauhu.dev) for a free developer key for building, testing and demos.
2. **Integrate and test** with the open tools.
3. **Deploy to production** with a licensed key per device from [pauhu.ai](https://pauhu.ai).

Questions and ideas are welcome in [Discussions](https://github.com/orgs/pauhu/discussions). Security reports: see [SECURITY.md](https://github.com/pauhu/.github/blob/main/SECURITY.md).
