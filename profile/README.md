# Where new frontiers become real

**The full general-purpose AI stack for builders, without the datacentre.**

Data retrieval, browser and computer use, specialised models and licensed multilingual data at origin, with results verifiable at source. Built for industry and regulation, from Linux and quantum to satellites, drones, robots and process plants.

## Why builders choose Pauhu

- **Runs on your hardware.** Models and tools work on the machine in front of you, offline when you need it.
- **Data at origin.** Licensed multilingual data comes straight from its publisher, with its version date and retrieval time.
- **Results you can prove.** Answers and runs carry a receipt that anyone can verify on the spot.
- **Open source.** Apache-2.0 tools you can read, build and extend.

## What you can build

| Area | Start here |
| --- | --- |
| Linux developers | `pauhu-origin`: cited answers about your own code and history |
| Quantum | `pauhu-quantum`: repeatable, verifiable simulator runs |
| Industrial AI | Receipts for vision inspection, factory data hubs, robots, drones and more, arriving one at a time |

Releases and packages for these tools are listed on their repository pages.

## Get started

1. **Sign in with GitHub** at [pauhu.dev](https://pauhu.dev) for a free developer key for building and testing.
2. **Build and test** with the open tools.
3. **Ship to production** with a licensed key per device from [pauhu.ai](https://pauhu.ai).

Questions and ideas are welcome in [Discussions](https://github.com/orgs/pauhu/discussions). Security reports: see [SECURITY.md](https://github.com/pauhu/.github/blob/main/SECURITY.md).
